# SOLO MATE — versión HTML

Versión independiente creada con HTML, CSS y JavaScript puro.

## Contenido incluido

- 35 productos.
- 42 fotografías.
- 6 categorías: Mates, Yerbas, Materas, Termos, Combos y Bombillas.
- Subcategorías, variantes de color, búsqueda y filtros.
- Carruseles en los productos que tienen más de una foto.
- Ficha individual para cada producto.
- 42 imágenes ajustadas al mismo formato vertical, sin recortes.
- Carruseles con flechas, miniaturas y deslizamiento con el dedo.

## Editar productos y precios

Abrí `products.js`. Cada producto tiene nombre, categoría, subcategoría, precio, colores e imágenes. Usá `price: null` para mostrar “Consultar precio”.

Las fotografías originales están dentro de `images/`. Las copias preparadas para la tienda, todas de 1200 × 1500 píxeles, están en `images-square/`.

## Configurar WhatsApp

Abrí `config.js` y completá `whatsapp` con código de país y solo dígitos. Ejemplo para Argentina: `54911XXXXXXXX`.

## Publicar en Vercel

Subí esta carpeta a GitHub, importá el repositorio desde Vercel y presioná **Deploy**. No necesita instalación ni comando de compilación.
